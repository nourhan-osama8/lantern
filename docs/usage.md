# Lantern Usage

Lantern is a simple command-line task tracker.

## Available Commands

- `lantern add`: Add a new task.
- `lantern list`: Display all tasks.

## Storage

Tasks are stored locally in a JSON file named `tasks.json`.

## Empty Task List

`No tasks found.`
